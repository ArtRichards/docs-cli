## Contract

### Goal

Agents using the standalone docs-cli bundled skill can discover how to record quality artifacts in a docs-managed tree without hand-editing generated indexes or confusing docs validation with test adequacy.

### Scope

- Update bundled skill prose and references only.
- Record the milestone and implementation log in the docs-cli docs tree.

### Out of scope

- Runtime CLI changes.
- Packaging version bumps.
- Publishing to PyPI.

### Invariants

- Metadata changes use docs-cli verbs where applicable.
- `INDEX.md` is regenerated by docs-cli.
- The skill bundle remains installable by `docs install-skill`.
